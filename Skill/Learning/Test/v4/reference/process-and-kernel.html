Process 與 kernel

Reference

Process 是正在執行的 program instance。它執行 user-space code，但許多整台系統共用的資源與狀態由 kernel 管理。

快速模型：Process 發出需求 → kernel 執行受控操作 → kernel 回傳該 process 可觀察到的結果。

Namespace 之所以有意義，是因為 kernel 可以在處理這些需求時，把 process 的 namespace membership 納入判斷。
