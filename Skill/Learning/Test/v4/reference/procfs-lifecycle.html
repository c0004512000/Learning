/proc 與 process lifecycle

Reference

/proc 是 pseudo-filesystem。它把 kernel 當下掌握的狀態用 filesystem 介面呈現給 user space。

生命週期：/proc/<pid> 跟著對應 process 的可見性與生命週期存在，不是普通檔案被背景工作稍後刪除。

/proc/<pid>/ns/* 提供 namespace object 的 reference/handle；它不是 namespace 本體。
