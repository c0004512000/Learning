/proc 與 process lifecycle

Reference

/proc 是 pseudo-filesystem。它不是一批由程式持續寫入磁碟的普通檔案，而是 kernel state 的 filesystem-shaped view。

生命週期：process 存在且對目前 procfs 可見時，/proc/<pid> 可見；process 結束後，對應 view 隨之消失。

/proc/<pid>/ns/* 可提供 namespace object 的 handle/reference；它不是 namespace 本體。
