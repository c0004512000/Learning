Label 與 Selector

Label 是資源帶著的鍵值標記，例如 app: shop。Selector 是選取條件，例如 Service 的 spec.selector。

判讀順序

  1. 確認正在比較同一 Namespace 內的 Service 與 Pods。
  2. 讀取 Service 的每一個 selector 鍵值。
  3. 逐一比對 Pod labels：每項都符合才選到。
  4. 忽略 selector 沒要求的額外 labels。
Pod labels:
  app: shop
  version: v2

Service selector:
  app: shop

結果：符合；version 不影響本次選取。

實際查看

在自己的練習環境，以實際 Namespace 和名稱替換範例：

kubectl -n ckad-lab get svc web -o yaml
kubectl -n ckad-lab get pods --show-labels
kubectl -n ckad-lab get pods -l app=shop

最後一行只是以標籤篩選 Pod，沒有驗證 HTTP 連線。
