如何帶回此網站

OpenMAIC README 說明可匯出離線 HTML 或 PPTX。取得輸出後，先檢查內容與外部依賴，再把靜態教材加入 repo 並新增課程連結。即時 AI 對話仍需要另外運行的服務，不會因為發布 HTML 就自動具備。
