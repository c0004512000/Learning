Linux Namespace 核心模型

快速複習卡 · 只收錄已在 Lesson 1 建立的知識

核心句：Linux namespace 是 kernel 依 process 的 namespace membership，對某一類全域資源提供隔離視圖的機制。

最小心智模型

名詞此階段需要知道的精確含義
Program儲存在 filesystem 中的程式內容；尚未執行時只是靜態資料。
Process正在執行中的 program instance。
Linux kernel管理 process、memory、filesystem、network 等底層系統資源的核心。
Namespace讓不同 process 對某類原本全域的 kernel resource 看見隔離 instance / view 的機制。
Membership某 process 對某 namespace type 屬於哪個 namespace object。
/proc/<pid>/ns觀察 process namespace membership 的 Linux 介面。

不要混淆

錯誤直覺修正
不同 namespace = 不同 Linux kernel錯。多個 namespace 可以共用同一顆 kernel。
namespace = container錯。Namespace 只是 container 使用的隔離機制之一。
namespace 只是 Docker/Kubernetes 的設定錯。它是 Linux kernel 機制，可以直接從 process 與 `/proc` 觀察。
現在就要背 PID/NET/MNT…不用。先理解每一類 namespace 都是在解「某個原本全域資源需要不同 view」的問題。

三個觀察指令

# 目前 shell 的 PID
echo $$

# 目前 shell 所屬的 namespace objects
ls -l /proc/$$/ns

# 比較目前 shell 與 PID 1 的 PID namespace identity
readlink /proc/$$/ns/pid
readlink /proc/1/ns/pid
