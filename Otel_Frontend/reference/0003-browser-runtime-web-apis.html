最短版本
source 是你部署的檔案；runtime 是 Browser 真正跑起來後的當下狀態。Browser 解析 HTML 建立 DOM、執行 JavaScript，並另外提供 Event、networking 等 Web APIs。

2. JavaScript 語言本身 vs Browser 額外提供

JavaScript language
├── 變數
├── if / for
├── function
└── Object / Array

Browser-provided APIs
├── document
├── addEventListener
├── fetch
└── localStorage

重點是責任邊界：有些能力屬於 JavaScript 語言；有些能力是因為 JavaScript 現在跑在 Browser 裡，所以由 Browser 額外提供。

4. document.querySelector()

document.querySelector('#buy')

從目前 Document 的 DOM tree 找第一個符合 #buy 的 element：

#buy        → id="buy"，tag 不限
button#buy  → id="buy" 且 tag = button
