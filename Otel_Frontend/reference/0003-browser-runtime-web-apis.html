Browser 是 Web Application 的 host environment；JavaScript engine 執行 ECMAScript；DOM、Event、fetch() 等能力由 Browser 暴露給 JavaScript。

4. document.querySelector()

document.querySelector('#buy')

意思：從目前 Document 的 DOM tree 找第一個符合 selector #buy 的 Element。

#buy        → id="buy"，tag 不限
button#buy  → id="buy" 且 tag = button

5. Source 與 live DOM

original HTML source
        ↓ parse
initial DOM

current live DOM

DOM 被改動，不代表原始 HTML response/source 被改寫。

同一個 JavaScript 語言可以跑在 Browser、Node.js 等不同 host environment；可用的 host APIs 與 security boundary 不必相同。
