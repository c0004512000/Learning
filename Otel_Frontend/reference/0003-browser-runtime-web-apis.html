最短版本：
Browser 是承接 Web Application 執行的環境；JavaScript engine 負責執行 JavaScript；DOM、Event、fetch() 等能力則由 Browser 提供給 JavaScript 使用。

2. JavaScript 語言本身 vs Browser 提供的能力

JavaScript language
├── Object

├── document

重點不是記另一個語言標準名稱，而是分清楚：有些能力屬於 JavaScript 語言本身；有些能力是因為 JavaScript 現在跑在 Browser 裡，所以 Browser 額外提供。

DOM 是 Browser 對目前 document 的 runtime object model；不是 JavaScript source，也不是 rendered pixel。

4. document.querySelector()

document.querySelector('#buy')

意思：從目前 Document 的 DOM tree 找第一個符合 selector #buy 的 Element。

#buy        → id="buy"，tag 不限
button#buy  → id="buy" 且 tag = button

5. Source 與 live DOM

original HTML source

DOM 被改動，不代表原始 HTML response/source 被改寫。
