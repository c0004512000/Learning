Faro 接手、導入與維運課程 · 目前位於 Lesson 1 of 12

Mission
透徹理解既有 Faro 解法，能說明它、協助前端導入、串接前後端可觀測性，並具備未來修改、優化與維運的能力。

目前位置

Lesson 1：瀏覽器基礎 — 進度 0 / 12。先建立 HTML、DOM、DOM event 與 event listener，尚未進入 Faro。

Milestone 1｜先看懂瀏覽器發生什麼

  1. 瀏覽器如何知道你點了哪裡
    目標：分清楚 HTML、DOM、畫面、DOM event 與 event listener。
    來源：Developer Introduction；缺少的瀏覽器前置知識。
  2. 點擊如何成為 Faro 資料
    目標：在瀏覽器基礎上，引入 ClickInstrumentation、payload 與 Transport。
    來源：Developer Introduction；ClickInstrumentation 程式碼。
  3. 一筆資料如何離開瀏覽器
    目標：確認瀏覽器邊界、HTTP request、Alloy endpoint 與接收結果。
    來源：PI 前端監控案例；Alloy 部署文件；runtime 設定。

Milestone 2｜讀懂並修改套件

  1. initFaro 的組裝責任 — 驗證、初始化順序與 singleton。
  2. Click payload 契約 — 屬性尋找、名稱轉換、空資料與節流。
  3. User 與 Device context — 同步時機與跨資料附加。

Milestone 3｜宿主專案導入與驗證

  1. Host integration checklist — 前端專案需要提供哪些設定。
  2. Browser DevTools 驗證 — 從 Network 面板確認 request、內容與 trace header。

Milestone 4｜串起前後端 Trace

  1. traceparent 因果鏈 — 瀏覽器 request 如何成為後端 trace 的 parent context。
  2. Success／Fail／Slow 實驗 — 用真實查詢驗證 trace 是否完整。

Milestone 5｜平台與維運

  1. Alloy → OTel Collector pipeline — receiver、batch、export 與環境差異。
  2. 查詢與 production troubleshooting — 使用 Loki、Tempo、OpenSearch 沿資料路徑定位問題。
目前不要求理解後面出現的專有名詞。 它們只是課程地圖上的目的地；Lesson 1 的測驗不會考它們。

課程順序依完整文件 corpus、Faro click tracking 程式碼、兩套 Helm repository 與實際環境驗證結果規劃；詳細教材仍會依學習狀況逐課生成。
