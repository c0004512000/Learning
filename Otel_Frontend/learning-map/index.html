Mission

接手並維運既有 Faro 前後端可觀測性方案。能用程式碼、Browser DevTools 與 runtime evidence，從瀏覽器事件追到 Alloy／OTel Collector、Tempo／Loki／OpenSearch，判斷資料如何流動、哪裡失敗，以及如何安全修改、導入與優化。

課程依概念依賴安排；既有 8 份主教材與 source evidence 支持完整規劃，詳細教材隨學習逐步展開。Mission 與範圍 · 課程規劃與來源對照

M0 必要的 Browser runtime 基礎 · M1 Browser event · M2 讀懂內部 SDK 的初始化與 context · M3 Host integration · M4 Frontend ↔ Backend distributed trace · M5 Alloy／Collector／storage pipeline · M6 Production deployment
