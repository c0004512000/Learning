瀏覽器如何知道你點了哪裡

先建立 DOM 與 DOM event，再談 Faro · Lesson 1 of 12

你在領班助手按下「每日生產排程」時，畫面可能會換頁或載入資料。但程式首先必須回答一個更基本的問題：

使用者剛才點了哪一個頁面元素？

這堂課只回答這個問題：瀏覽器如何把一次點擊交給網頁程式。

1. 網頁交給瀏覽器三種材料

當你開啟領班助手，瀏覽器會取得網頁需要的檔案。先把它們理解成三種分工：

材料 它回答的問題 這堂課的例子
HTML 頁面上有哪些東西？ 有一顆「每日生產排程」按鈕
CSS 這些東西長什麼樣子？ 按鈕的顏色、大小與位置
JavaScript 操作之後要做什麼？ 按下按鈕後執行一段程式

這三種檔案都由瀏覽器讀取。這裡的「前端」就是下載到瀏覽器、由瀏覽器執行的網頁部分。

2. HTML 只是文字，瀏覽器需要可操作的版本

HTML 可以包含下面這段文字：

<main>
  <button>每日生產排程</button>
</main>

瀏覽器讀完後，會在自己的工作記憶體裡建立一份頁面結構：

main
└── button
    └──「每日生產排程」
DOM（Document Object Model） 是瀏覽器根據 HTML 建立的可操作頁面結構。JavaScript 可以用它找到按鈕、讀取文字或改變頁面。

因此，下面三者不是同一件事：

名稱 它是什麼
HTML 瀏覽器取得的原始標記文字
DOM 瀏覽器根據 HTML 建立的可操作結構
畫面 瀏覽器依照 DOM 與 CSS 畫給人看的結果

3. 點擊發生時，瀏覽器建立一筆通知

使用者按下按鈕時，瀏覽器會建立一筆資料，記錄「剛剛發生了點擊」。這筆通知叫做 event（事件）。

因為這次點擊發生在 DOM 裡的按鈕上，所以它也叫做 DOM event。

click 是事件種類。event.target 指向這次實際被點到的 DOM 頁面項目。

在本例中，event.target 指向「每日生產排程」按鈕，而不是整張畫面，也不是 HTML 檔案。

4. JavaScript 如何收到這筆通知？

函式是一組可以被呼叫執行的程式指令。JavaScript 必須事先告訴瀏覽器：「有點擊時，請呼叫這個函式。」被登記來接收通知的函式叫做 event listener（事件監聽器）。

document.addEventListener('click', handleClick)

先不用背語法。它現在只表示：

頁面中發生 click event 時，瀏覽器呼叫 handleClick。

5. 用真實情境重走一次

  1. 領班助手的 HTML 宣告一顆「每日生產排程」按鈕。
  2. 瀏覽器根據 HTML 建立 DOM，其中包含這顆按鈕。
  3. 你按下按鈕。
  4. 瀏覽器建立 click event。
  5. event.target 指向被點到的按鈕。
  6. 瀏覽器呼叫事先登記的 event listener。

到這裡，我們只知道瀏覽器如何把一次點擊交給 JavaScript。下一堂才會把前端監控套件接在這個既有機制後面。

Recap

  • HTML 描述頁面有哪些東西。
  • DOM 是瀏覽器根據 HTML 建立的可操作頁面結構。
  • 畫面是瀏覽器依 DOM 與 CSS 呈現給人看的結果。
  • 點擊發生時，瀏覽器建立 click event。
  • event.target 指向實際被點到的 DOM 元素。
  • Event listener 是事先登記、由瀏覽器在事件發生時呼叫的 JavaScript 函式。
