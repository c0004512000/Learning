Deploy Alloy Server - Production

Confluence page ID: 2204696116 · Source: https://confluence.garmin.com/display/PI/Deploy+Alloy+Server+-+Production

透過 helm chart 安裝

https://artifacthub.io/packages/helm/grafana/alloy

helm chart value 

  • 詳細可參考: stage 的 alloy values.yaml
  • 記得要新增一個 production.values.yaml
  • 目前需要設定 stability.level, 預設是 generally-available / stable, 但目前使用的 otelcol.receiver.faro 處於實驗性階段, 所以採用 experimental, 想了解關於那些 component 屬於 experimental, 可以查看 otelcol.receiver.faro 官方文件
  • 可以參考 tw-stage Alloy extraArgs
  extraArgs: 
    - --stability.level=experimental
    - --disable-reporting

ConfigMap

faro receiver 

port 預設是開 12347

  extraPorts:
    - name: "faro"
      port: 12347
      targetPort: 12347
      protocol: "TCP"


cors policy

需要設定 cors policy 才有辦法接收到 faro 傳送的 data.
若需要串接 trace, alloy & backend 都需要設定 allowed_headers

configMap:
	...
	cors {
		allowed_origins = ["*" or 任何允許的 domain]
		allowed_headers = ["*" or 任何允許的 headers]
	}

processor

目前使用 batch 做批次處理, 再送到 expoter.

otelcol.processor.batch "default" {
  output {
    logs = [otelcol.exporter.otlp.collector.input]
    traces = [otelcol.exporter.otlp.collector.input]
  }
}


exporter

Alloy server 會將資料轉送到現有的 OTel Collector 

otelcol.exporter.otlp "collector" {
  client {
    endpoint = "opentelemetry-collector.open-telemetry.svc.cluster.local:4317"
    tls {
      insecure = true
    }
  }
}

暴露 Alloy Server

virtualService:
  hosts:
    - pek8s-staging.garmin.com # 要換成該環境的 domain
  http:
    - match:
        - uri:
            regex: /alloy(/|$)(.*)
      rewrite:
        uri: /\2
      route:
        - destination:
            host: alloy
            port:
              number: 12347
