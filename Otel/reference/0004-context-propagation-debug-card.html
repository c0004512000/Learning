Context propagation debug 卡

沿 request boundary 找斷點，不把 export 與 propagation 混為一談

正確不變量

Sender CLIENT Span: trace=T, span=A
traceparent:          trace=T, parent=A
Receiver SERVER Span: trace=T, span=B, parent=A

T 相同；B 必須是新 ID；B.parent 必須等於 A。

五站檢查

  1. Sender current Span 是否正確？
  2. Inject 後 carrier 是否有合法 traceparent？
  3. Proxy / gateway / library 是否保留 header？
  4. Receiver 是否在建 Span 前 extract？
  5. 兩端 propagator format 是否相容？

症狀對照

症狀先查
Outgoing 無 headersender inject / current context
Header 抵達但 receiver 是 rootextract / format / 建立順序
Trace ID 相同但 parent 錯current Span / context lifecycle
Spans 都可 export 但 Trace 分裂propagation，不是 exporter
Header 正確但 backend 缺 Spansampling / SDK pipeline / exporter
安全：外部 context 可被偽造；Baggage 不可放 credential、API key 或 PII。
