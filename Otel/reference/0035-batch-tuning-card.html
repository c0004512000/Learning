Batch Tuning Card

先量 workload 與 backend constraint，再調三個 knobs

  1. Units：spans/datapoints/log records 的 rate、bytes/item 分布與壓縮率。
  2. Trigger：send_batch_size 是 send threshold，不是 hard maximum。
  3. Maximum：send_batch_max_size 限 item count，不保證 byte size。
  4. Timeout：低流量下的額外等待上界之一，不含 exporter/network/backend latency。
  5. Order：memory limiter → drop/sampling → batch 通常較合理。
  6. Evidence：batch items/bytes histogram、size/timeout trigger count、request failures、queue age。
  7. Failure unit：大 batch 失敗時重試、duplicate、memory 與 partial rejection 影響更大。
