Collector Upgrade Card

升級的是 binary + components + config + semantics + state + observability

  1. Pin target image digest；比對 distribution manifest/component set。
  2. 逐跨越版本讀 core、contrib、releases changelog 與 component README。
  3. 列出 breaking/deprecated/default/feature-gate/stability changes。
  4. 用 target binary resolve/validate final config；不要只改 image tag。
  5. Diff semantic fixtures、canary、selection ratios、cardinality、internal metrics。
  6. 測 peak、outage、restart、queue/WAL/storage 與 stateful rebalance。
  7. 定義 canary cohort、observation window、rollback trigger 與 queue/state treatment。
  8. 確認 rollback artifact 可取；若 storage/schema 不向後相容，準備 roll-forward。
