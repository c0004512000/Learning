沒有 trace_id

  1. Log emit 時是否真的位於 current Span 內？
  2. Async/thread boundary 是否保留 Context？
  3. Logging bridge 是否擷取 trace fields？
  4. Exporter/Collector/backend mapping 是否保留？

  1. 同一 logger 是否有多個 handlers？
  2. logger.propagate 是否又送到 root handler？
  3. 是否同時 direct OTLP 與 stdout/file collection？
  4. Collector 是否有重複 receivers/routes？
