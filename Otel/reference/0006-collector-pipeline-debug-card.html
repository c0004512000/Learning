Collector pipeline 與分站 debug 卡

沿 active data path 定位，不把 Collector 當黑盒

Source → Receiver → Processor(s) → fan-out → Exporter(s) → Backend
站點責任證明不了什麼
Receiver接受 / 取得 / 解碼不證明後續 export
Processor依序 transform / batch / drop不保證一定 forward
Exporter送到外部 destination不建立 application Span
Pipeline啟用並連接 signal path頂層定義不等於已啟用

Backend 無資料：四站

  1. Receiver protocol / port / signal。
  2. Processors 是否 drop / transform。
  3. Exporter endpoint / TLS / auth / queue / retry。
  4. Backend ingestion / tenant / time range / query。
Debug exporter：有資料表示 receiver 與前置 processors 已通過；不代表其他 exporter 或 backend 成功。
