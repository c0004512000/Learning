Instrumentation 分層判斷卡

讓最了解語意、又最能穩定維護的 layer 負責

Layer最懂什麼不該猜什麼
Zero-code/frameworkRuntime hooks、HTTP/RPC/DB edgesDomain intent、business outcome
Library instrumentation該 library 的 public operations/protocolApplication SDK/export policy
Manual applicationUser journey、domain stages、business metrics重複底層已標準化 network spans
CollectorRouting、policy、已存在 telemetry fieldsSource 從未記錄的 hidden business state

重複 Span：先比 scope name/version、kind、name 與 timing；關掉或移動一個 owner，不先靠 backend dedup。
