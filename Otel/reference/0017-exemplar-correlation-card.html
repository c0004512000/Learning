Metric point → representative measurement → Trace

Histogram bucket/count/sum
  └─ Exemplar
       value + timestamp
       trace_id + span_id (optional)
       filtered attributes (optional)
            └─ Trace backend lookup

Exemplar 沒出現時

  1. Measurement 是否在有效 current Context 中記錄？
  2. TraceBased filter 下，current Span 是否 sampled？
  3. Reservoir 是否選中該 eligible measurement？
  4. Exporter/Collector/backend 是否保留 exemplars？
  5. UI/query 是否支援顯示？

不要：把 trace ID 當 metric attribute；那會為每筆 request 建新 series。
