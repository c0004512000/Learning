OTTL Review Card

每條 statement 都回答六個問題

  1. Context：目前迭代的是 resource、span、spanevent、metric、datapoint 還是 log？
  2. Target：哪個 path 會被修改或刪除？
  3. Input type：function 期待什麼型別；nil/錯型別時怎樣？
  4. Condition：where 為 false 時必須保持什麼不變？
  5. Order：前一條 mutation 是否改變後一條的 input/condition？
  6. Error mode：ignore、silent、propagate 對可見性與 loss 的影響？

安全檢查：用代表性、missing、錯型別、敏感值、極端 cardinality 五組輸入做 truth table。
