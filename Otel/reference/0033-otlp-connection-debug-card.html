OTLP Connection Debug Card

一次只證明一層；不要把所有錯誤統稱 TLS

  1. Name/route：DNS、IP、port、service、proxy、network policy。
  2. TCP：拒絕、timeout、reset，與 server 是否真的 bind 該 interface。
  3. TLS：protocol version、trust chain、SAN/hostname、有效期、clock、client certificate。
  4. Authentication：token/cert principal 是否被接受；authentication 不等於 authorization。
  5. OTLP：gRPC vs HTTP、4317 vs 4318、path/content type/compression 是否一致。
  6. Pipeline：receiver accepted、processor dropped、exporter failed/retried/sent。

禁止捷徑：不要用 insecure_skip_verify 當永久修復；它會移除 server identity verification。
