Span Limits 與缺失資料判斷卡

「看不到欄位」是一個症狀，不是一個根因

  1. Instrumentation 是否真的呼叫 set/add？
  2. 該 Span 是否 recording，且寫入發生在 end 前？
  3. SDK count/value-length limits 是否 discard 或 truncate？
  4. Processor/exporter/protocol 是否保留 dropped counts 與值？
  5. Collector processors 是否 filter/transform？
  6. Backend ingestion/index/UI 是否另有限制？
