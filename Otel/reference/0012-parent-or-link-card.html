Parent 還是 Link？

先描述 causality，再選 telemetry topology

情境較合理的模型原因
同步 nested callParent/child單一主要執行脈絡
一則 message 延續原工作，保留同一 TraceExtracted context 作 parent跨 process continuation
多則 messages 合成一個 batch新 Span + multiple Links多個 causal inputs，parent 只能一個
延遲／獨立排程的新工作新 Trace + Link（視語意）保留關聯但不偽裝成單一 nested lifetime

檢查：Link 不會改變新 Span 的 trace ID，也不把 linked Span 變成 parent。
