Collector 設定解析卡

Source → Resolve → Merge/Override → Decode → Build Graph → Start

  1. Source：實際讀了哪些 file/env/yaml/http(s) config URIs？
  2. Resolve：每個 substitution/reference 最終變成什麼？缺值是否變空字串？
  3. Merge：多來源與 --set 後的 final config 是什麼？
  4. Decode：distribution/version 是否認得 component type 與欄位？
  5. Graph：所有 pipeline reference 是否指向已宣告 instance，signal 型別是否相容？
  6. Runtime：port、DNS、TLS、credentials、permissions 是否可用？

安全原則：檢查 final config 時遮蔽 secrets；比較結構與來源，不把 credential 寫入 ticket/log。
