第一個失敗邊界判斷卡

不要問「哪裡可能壞」；問「最後一個已證明成功在哪裡」

  1. 精確定義 signal、entity、record/stream、time window。
  2. 畫 source → SDK → transport → Collector → backend → query。
  3. 每條箭頭寫 success contract 與正面證據。
  4. 找最低已通過層，測試緊鄰下一層。
  5. 一次只改一個變因，保留 before/after evidence。
  6. 修復後從 source 到 query 重走 contract，避免局部假成功。

禁忌：Backend 查不到 ≠ source 沒產生；沒有 error log ≠ export 成功；ready ≠ payload 通過。
