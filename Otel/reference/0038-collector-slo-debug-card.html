Collector SLO Debug Card

從 violated user outcome 倒推到第一個失敗 boundary

  1. 說清 SLO boundary、signal、tenant/region、時間窗與 expected population。
  2. Availability、known loss、freshness、correctness、coverage，哪個 SLI 壞？
  3. Canary 是否也壞；internal telemetry path 是否與 data path 共因失效？
  4. 逐 hop 比對 receiver accepted/refused、processor selection、queue/enqueue failure、export sent/failed。
  5. 把 intentional sampling/filter 從 unexpected loss 分母中明確建模。
  6. 找 first bad boundary，而非最後一個報錯 component。
  7. 以 error-budget burn 決定 alert urgency；修復後用 end-to-end outcome 關閉 incident。
