Routing Proof Card

對每種代表性輸入，算出 ordered evaluation 與 destination set

  1. 列出 input identity、signal、metadata 與缺值情況。
  2. 依 table order 評估每條 predicate。
  3. copy：加入 destination，原資料繼續；move：加入 destination，停止後續評估。
  4. 未被 move 的剩餘資料，確認是否進入 default_pipelines。
  5. 記下可能 destination set、duplicate、zero-route 與 error fallback。
  6. 確認每個目的 pipeline 都以同一 connector 為 receiver，且 signal 型別一致。
  7. 安全路由只採信已驗證 identity；app 可自行填的 attribute 不等於 authorization。
