OTel 最小 lab 證據階梯

每一層只證明一件事，避免從「沒看到 Trace」跳到單一結論

層級成功證據它不能單獨證明
1. Config materializedCompose 展開後的 image、mount、port 符合預期Collector 已成功啟動
2. Collector startupConfig 被接受，OTLP/HTTP receiver readyHost port 可達
3. Host-to-container reachabilityApplication 不再收到 connection/protocol errorSpan 已通過完整 pipeline
4. Receiver accepted telemetryCollector 有接收或處理證據debug/backend exporter 成功
5. Debug exporter output預期 service、span、attributes 出現在 Collector logProduction backend 已保存且可查詢

規則：先找最低一個尚未成立的層級；修復後重跑相同證據，再往上一層。
