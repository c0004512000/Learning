OTLP Delivery Debug Card

先找 acknowledgment boundary，再分類 outcome

  1. 誰是 client、誰回 response、該 hop 的 batch identity/time window 是什麼？
  2. Full success、partial success、retryable failure、non-retryable failure，屬於哪一類？
  3. 是否收到 RetryInfo / Retry-After；backoff、jitter、deadline 如何？
  4. Queue 長度/容量、oldest age、retry count、dropped count 是否支持推論？
  5. Response/ack 是否可能遺失，造成同一 request 重送與 duplicates？
  6. Multi-destination 是否各自有 queue/ack 狀態，還是慢端拖住快端？
  7. Server accepted 是否只到 Collector memory/queue；下一 hop 的 evidence 在哪？
