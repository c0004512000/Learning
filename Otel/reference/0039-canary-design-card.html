Telemetry Canary Design Card

已知輸入 + 唯一 marker + 可查詢 assertions + 安全邊界

  1. Canary 從哪個 producer/network/auth path 發出？與真實 traffic 共用哪些 boundary？
  2. Trace/metric/log 各自的 exact input 與 correlation 是什麼？
  3. Marker 如何唯一、可查、可過期，且不造成 metric cardinality explosion？
  4. Arrival、freshness、count、relationship、resource、redaction、routing assertions 是什麼？
  5. Negative assertions：不該到哪、不該含什麼、不可 duplicate 幾次？
  6. Failure attribution：producer、ingress、policy、egress、backend query 哪一層有 evidence？
  7. Canary 自身 scheduler/query/credential 如何監控，避免把 probe failure 誤判 data path failure？
