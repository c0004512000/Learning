Connector 除錯卡

把 connector 視為兩條 pipeline 之間有型別、有狀態的 edge

  1. 宣告：目標 Collector distribution/version 真的包含該 connector 嗎？
  2. 上游：connector 是否出現在來源 pipeline 的 exporters？
  3. 下游：同一 instance 是否出現在目的 pipeline 的 receivers？
  4. 型別：來源/目的 signal pair 是否受支援，例如 traces → metrics？
  5. 輸入：上游 connector 前是否真的有 spans；sampling 是否已先丟棄資料？
  6. 狀態：flush interval、TTL、cache、cardinality limit、affinity 是否符合預期？
  7. 輸出：下游 processor/exporter 的 accepted、failed、dropped evidence 是什麼？

最短定位句：先證明 edge 左邊有輸入，再證明 edge 產生輸出，最後才查 backend。
