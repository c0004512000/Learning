Sampling 決策與缺 Trace debug 卡

Sampled 是決策，不是 delivery receipt

三種 SDK 決策

DecisionRecordSample / export
DROP否否
RECORD_ONLY是否
RECORD_AND_SAMPLE是是

Head vs Tail

Head：早決策、低成本、看不到最終 outcome
Tail：晚決策、可看 errors/latency、需要 state 與 buffer

Backend 缺 Trace：六站檢查

  1. Instrumentation 有建立 Span？
  2. Sampler decision 是什麼？
  3. Span 有 end，queue / flush 正常？
  4. OTLP transport 成功？
  5. Collector processor 有 drop？
  6. Backend ingestion / retention / query 正確？
不變量：trace-flags=01 表示 sampled decision；不保證 Processor、Exporter、 Collector 或 backend 已成功處理資料。
