Resource identity 快速判斷卡

先問「它描述哪一個 entity、多久改一次？」

AttributeIdentity level何時相同何時改變
service.namespace系統／應用群組同一邏輯系統內的 services歸屬模型改變
service.name邏輯 service所有水平 replicasservice boundary 真正改名
service.instance.id執行中 instance只屬於該 instance新的 runtime instance
service.version部署 artifact/cohort同一版本部署新版本
deployment.environment.name部署環境同一 logical environment移到另一環境

三個快速反例

  • service.name=checkout-pod-a7f9：把 instance 塞進 logical service，會拆碎 service view。
  • service.instance.id=checkout：replicas 互相碰撞，無法隔離單一 instance。
  • 把 cart.item_count 放 Resource：operation-specific value 被錯誤套到 provider 的所有 Spans。
