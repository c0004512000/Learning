怎麼使用這張地圖

每章可展開「Lesson → 目標 → 操作驗收 → 來源」。這是完整主線，不是固定週次表；若你已能實作某能力，就以證據略過或加深。未來課文只在走到那一步時撰寫。半年約 26 週、每週 5 小時：約 130 小時，涵蓋閱讀、練習、複習與模擬；每堂投入時間依難度調整，不是 34 堂上完便保證通過。

章節與 Lesson

5 堂 · 目前

01 基礎：看懂叢集如何運作 →

先建立共同語言與觀察能力，不把 SRE 經驗直接算作已掌握。

Kubernetes 解決什麼問題、容器、Pod 與生命週期、API 物件與宣告式狀態、kubectl、context、namespace、控制平面與節點的協作

5 堂 · 規劃中

02 工作負載：能部署、設定與排程 →

先能讓程式穩定運作，才談進一步排錯。

Deployment 與副本、更新、回復與自癒、ConfigMap、Secret 與設定注入、資源、探針與自動擴縮、排程與准入

6 堂 · 規劃中

03 網路：能連線、限制與導流 →

從 Pod 互通逐層到對外入口，判斷流量卡在哪一段。

Pod IP 與跨節點互通、Service 與 EndpointSlice、ClusterIP、NodePort、LoadBalancer、CoreDNS 與服務發現、NetworkPolicy、Ingress 與 Gateway API

3 堂 · 規劃中

04 儲存：能讓資料跨 Pod 存活 →

先認識掛載，再理解供應、綁定與回收。

Volume 與容器檔案系統、PV、PVC 與存取模式、StorageClass 與動態供應

7 堂 · 規劃中

05 叢集管理：能建立、授權與維護 →

接上基礎架構模型，練 CKA 特有的管理任務。

安裝前提與 kubeadm 建立叢集、叢集生命週期與升級、控制平面高可用與 etcd、RBAC 與身分授權、Helm 與 Kustomize、CNI、CSI、CRI、CRD 與 Operator

5 堂 · 規劃中

06 故障排查：能用證據縮小故障路徑 →

前面的章節將安排小型排錯；此處整合節點、控制平面與服務。

工作負載與事件、Node NotReady 與資源壓力、控制平面與叢集元件、資源用量與容器輸出、Service、DNS 與網路故障

3 堂 · 規劃中

07 綜合應試：能限時操作與驗收 →

在完成各主題實作後整合；不以看完教材當作準備完成。

混合題與文件定位、限時模擬與錯題回補、考前能力缺口複驗
