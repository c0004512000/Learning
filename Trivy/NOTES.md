# 教學備註

- 使用者指定 @lfd / Learning-from-docs Skill；必須使用 GitHub Learning Repo + GitHub Pages，不能以 Library 下載檔取代。
- 視覺採用 Skill 的 `personal-learning-preferences/assets/style.css` 和 `theme.js`，維持 dark-first、mobile-first、serif 閱讀版面。
- 第一章必須是可閱讀的正式 Lesson；Course Map 不可取代完整教材。
- 用臺灣繁體中文、第一性原理、可驗證實例，控制術語數量。
- 學習完成（assessed）、教材撰寫完成（authored）與 CI 實測完成（verified）必須分別標示。
- 未能取得實際 UI 時，不偽造截圖或瀏覽器測試結果。
