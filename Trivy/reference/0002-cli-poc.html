Filesystem CLI PoC 速查

先完成 CLI、DB、Output 基礎，再進行受控實驗。不需要 Docker 或 Image Scan。

完整受控實驗 →

trivy --cache-dir ./cache fs --download-db-only
trivy --cache-dir ./cache fs --scanners vuln --skip-db-update \\
  --list-all-pkgs --format json -o reports/old.json old

對照 old、fixed、empty 的套件辨識及指定 CVE；分開驗證 exit code 與篩選。詳見 CLI / DB / Output 速查。
