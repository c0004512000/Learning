# Phase 02 CLI PoC 教學查核（2026-11-19）

- [Filesystem CLI](https://trivy.dev/docs/latest/guide/references/configuration/cli/trivy_filesystem/)：確認 --scanners、--format、--output、--list-all-pkgs、--exit-code 等旗標；Packages 用來核對套件辨識，不能只看 Vulnerabilities。
- [Image CLI](https://trivy.dev/docs/latest/guide/references/configuration/cli/trivy_image/)：--image-src docker 可限定本機 Docker 來源。
- [Reporting](https://trivy.dev/docs/latest/guide/configuration/reporting/)：Table、JSON、SARIF 與 convert；以實際工具版本 help 核對。
- [Exit code](https://trivy.dev/docs/v0.75/guide/configuration/others/)：預設有安全發現亦正常回傳 0；--exit-code 指定有發現時的代碼。執行錯誤不能單靠漏洞數解讀。
- [CVE-2024-35195 公告](https://github.com/advisories/GHSA-9wx4-h78v-vm56)：受影響版本 requests < 2.32.0。課程選 2.31.0 與 2.32.5 對照該 CVE；不宣稱後者所有漏洞均已修正。
- [既有 PoC 與公司 Workflow 靜態查核](2026-11-18-source-baseline.md)：沿用已記錄的特定樣本辨識數據；不代表重跑或公司 Runner 實測。
