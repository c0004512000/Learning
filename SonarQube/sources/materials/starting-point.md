# Learner-designated starting material / 2026-11-06

使用者明確希望以原有對話中的分析架構圖為視覺參考，製作新的 HTML 課程並發佈到 Learning GitHub Pages 的 `SonarQube/` 子目錄。

原始問題核心：

- 先理解 SonarQube 是什麼、內部如何運作，尤其 Scanner、Server、DB、Dashboard、Quality Gate 的資料與控制流程。
- 免費、不採用付費版。
- 先做小型 POC，接著做 GitHub Actions 整合、Dashboard、品質門禁、Kubernetes 正式部署的評估。
- 套用 Learning-from-docs 的來源與教學原則，但新建一套視覺 CSS，方向為深色底、簡潔灰藍框線與青綠色核心服務。
