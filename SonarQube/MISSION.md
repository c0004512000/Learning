# Mission: SonarQube Community Build 導入能力

## 要達到的能力

能解釋 SonarQube 的因果模型（Scanner → Server/Compute Engine → Database/Dashboard → Quality Gate），辨認免費版的 branch/PR 限制，設計不影響既有 Production 的本機 / CI POC，評估如何安全地整合 GitHub Actions、self-hosted Runner、Kubernetes、持久化 DB 與既有部署 Gate，最後產出可驗證的 rollout 決策。

## 限制

- 不採用 SonarQube 付費版。
- 從第一性原理循序學習，不把既有 SRE 經驗直接當作已掌握 SonarQube。
- 先單 repo、非阻擋、使用合成範例；不要在未核准環境直接部署或安裝軟體。
- Learning 是公開 repo；不得收錄公司敏感資訊。
- 課程地圖完整規劃、詳細 Lesson 逐步撰寫，進度依作答與操作證據更新。

## 現況

2026-11-06：已建立 7 階段、14 堂的主線。已撰寫 Lesson 01–02；目前尚無學習者理解驗收與 POC 執行證據。
