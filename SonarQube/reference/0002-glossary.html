術語速查

只保留主線需要且容易混淆的名詞；每個定義都與實際執行位置對應。

術語定義與邊界
Static Analysis不需要執行完整應用程式，以程式碼與規則檢查潛在問題；不等於功能測試。
SAST以靜態分析方式檢查應用程式安全風險，免費版提供基礎檢查但不含所有進階能力。
SonarScanner在開發機或 CI Runner 上執行的分析工具；產生與提交分析報告。
Analysis ReportScanner 在 Runner 分析原始碼後產生的結構化資料包（例如分析得到的 Issues / Metrics 與來源資訊），供 Server 後續處理；不是 Dashboard 上的使用者報表。
Compute EngineSonarQube Server 中非同步整合 Scanner 結果的背景元件，負責彙總、計算衍生指標／評級、處理 Issue 關聯與保存結果；並非重新執行相同的原始碼規則掃描。
ProjectSonarQube 中保存某份程式碼品質狀態的邏輯對象，包含分析資訊、Issues、Metrics、品質設定與歷史；不等於 Kubernetes Namespace。
Project Key用於在 SonarQube Server 識別 Project 的唯一鍵。Scanner 可使用 sonar.projectKey 指定分析報告的歸屬。
Issue分析規則偵測出的疑慮；需要評估真實影響與修正優先級。
Rule定義一種特定程式碼寫法是否違規的檢查條件；同一 Rule 可能偵測到很多 Issues。
New Code依時間、版本或特定分析所定義的新／修改程式碼範圍；不同於「在 PR 上進行原生差異分析」。
Quality Profile某語言採用哪些分析規則的組合；決定「檢查什麼」。
Sonar way core / extended / comprehensiveCommunity Build 26.10 的三種內建 Quality Profile，嚴格程度不同；升級舊版的現有設定不一定被自動改寫。
Quality Gate綜合品質條件給出通過／失敗結果；決定「是否過關」，不等同 CI 必然阻擋。
Coverage測試覆蓋率資料，由外部工具先產生後再匯入；Scanner 本身不負責執行測試。
DashboardSonarQube Server 提供的 Web UI，用來查詢 Project、Issues、Metrics 和 Gate。
H2可供本機短暫測試的內建資料庫，不建議在 Production 使用。
