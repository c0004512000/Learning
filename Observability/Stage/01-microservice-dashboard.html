01. MicroService Dashboard：三條 signal 如何在一頁相遇

先從已看到的 Dashboard 結果反推：這個 Dashboard 同時使用 Prometheus、Loki、Tempo。

Stage 已證實： Prometheus datasource UID prometheus、Loki UID loki123、Tempo UID temp123；variables 包含 Job、Namespace、Severity、DB_SYSTEM、Duration、Method、Url、node。

同一個 Namespace filter，三種 backend 寫法不同

# Prometheus
namespace=~"$Namespace"

# Loki
k8s_namespace_name=~"$Namespace"

# Tempo
resource.k8s.namespace.name=~"$Namespace"

因此 Dashboard variable 的價值，是把同一個人類概念映射到三種不同資料模型。
