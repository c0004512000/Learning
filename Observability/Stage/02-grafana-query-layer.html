02. Reference：Grafana Datasource → Variable → Query → Panel

1. Datasource：Grafana 去哪裡問

Datasource 保存 backend type、URL、query options 與 UID。Dashboard target 再用 UID 綁到 datasource。

Panel target
  datasource.uid = "prometheus"
        ↓
Grafana datasource
  type = prometheus
  url  = http://prometheus-server.prometheus.svc.cluster.local
        ↓
Prometheus query API

2. Variable：使用者要看哪個範圍

例如 label_values(namespace) 先取得可選值，再把選中的值放進 $Namespace。

3. Query：從 backend 選什麼、算什麼

PromQL 操作 time series；LogQL 操作 log streams；TraceQL 操作 traces/spans。Grafana 不會自動把三種 query language 互換。

4. Panel：怎麼呈現 query result

Panel 決定 time series、stat、table、unit、legend、threshold、field overrides、transformations 等 presentation。

5. Layout：用什麼順序支援 troubleshooting

Row、section、panel order 是 information architecture，而不是 telemetry generation。
