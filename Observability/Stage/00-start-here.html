Reference 到底是什麼？

這裡的 reference 不是特殊系統功能，本質就是 HTML 的相對連結：<a href="02-grafana-query-layer.html#datasource">。只要這些 HTML 放在同一個 directory，瀏覽器就能用相對路徑找到下一頁。

主線頁會放一個 anchor，例如 id="after-query-reference"。Reference 頁的「回主線」則會連到 01-microservice-dashboard.html#after-query-reference。這樣回來不是只到第一頁頂端，而是回到你剛才離開的位置。
