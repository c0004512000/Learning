# Observability Resources

## Delivery Standards

- [HTML → GitHub Pages 標準交付 Prompt](./HTML-GITHUB-PAGES-STANDARD-PROMPT.md)
  - 用於將學習教材、技術文件或知識頁面整理成多頁 HTML 並發布到 GitHub Pages。
  - 規範內容結構、閱讀順序、reference / anchor、相對路徑、mobile、互動功能、靜態 QA、browser smoke test 與 GitHub Pages 上線後驗證。
  - 未完成實際驗證的項目不得宣稱已正常運作。
