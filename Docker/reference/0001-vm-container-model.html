VM 與 Container：第三堂延伸參考

此頁供 Session 03 學習 Linux Kernel 與隔離機制後延伸閱讀：VM 有獨立 Guest Kernel，Linux Container 共享 Host Kernel。若還沒認識 Container，請先從第一堂開始。

先建立的七個名詞

Runtime
讓程式得以執行的軟體，例如 Python。
Library
程式引用的套件或現成功能。
Image
程式與大量執行依賴的版本化封裝，用來建立 Container。
Process
正在執行的一個程式實例。
Kernel
作業系統管理 Process、Memory 等資源的核心。
Hypervisor
提供 VM 虛擬硬體的管理程式。
System Call
執行中的程式向 Kernel 請求系統功能。

重要界線：Linux Container 可以在 Linux VM 裡執行；使用 Windows/macOS Docker Desktop 時，Linux Containers 通常由內部 Linux 虛擬環境提供 Kernel。
