DOCKER FUNDAMENTALS / FIRST PRINCIPLES / PREPARATION FOR CKA

從 Container 是什麼開始，
理解 Docker 如何運作。

8 堂、每堂約 30 分鐘的工程師內部分享。從一般程式如何執行出發，先建立 What，再完整討論 Why，最後理解底層機制、Dockerfile、Build Cache、Network、Storage，以及如何銜接 Kubernetes／CKA。

Mission：能理解原理、推論現象，而不只會複製指令

學員應能說明 Docker／Container／Image 的關係；解釋 Container 的隔離；預測 Dockerfile 與 Cache 行為；驗證資料與網路邊界；理解 Runtime 如何連接 Kubernetes。

完整課程安排

01 · What Is a Container & Docker?

從程式與 Process 開始，建立 Container、Dockerfile、Image、Container 的關係。

02 · Why Containerization?

傳統部署、環境漂移、依賴衝突、版本化 Artifact 與容器化的取捨。

03 · How Containers Work

Linux Kernel、Namespaces、cgroups、Root Filesystem，最後再比較 VM。

04 · Dockerfile & Image Layers

建構上下文、Dockerfile 指令、Filesystem Layer 與 Image Metadata。

05 · Docker Build Cache & Best Practices

Cache 命中與失效、指令排序、CMD／ENTRYPOINT、COPY／ADD、Multi-stage。

06 · Container Lifecycle & Storage

主要 Process、啟停、Container 可寫入層、Volume 與 Bind Mount。

07 · Docker Networking

Bridge、DNS、Port Mapping 與 Frontend／Backend 雙網路代理實驗。

08 · From Docker to Kubernetes

dockerd、containerd、runc、OCI、CRI 與 Kubernetes 管理需求。
