Docker，先懂原理，
再學指令。

五次各 30 分鐘的工程師內部分享。從部署差異開始，逐步理解 Container 隔離、Image 建置、網路、儲存，最後銜接 Kubernetes／CKA。

本課程的成功標準

遇到問題時，可以用正確的底層模型推論，而不是死記 Docker 指令。首堂不要求事先懂 Kernel 或虛擬化。
