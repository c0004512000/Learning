從第一個 Process，

為一般軟體工程師設計的 Docker 前置課程。不是 CLI 指令大全，而是從部署需求，推導 Kernel 隔離、Image 封裝、Network 與 Container Runtime。

Mission

五次各 30 分鐘的分享，讓非 SRE 背景的開發同事建立能解釋、判斷和觀察的 Container 知識，作為後續 CKA / Kubernetes 教學的共同基礎。

整套課程的學習順序

Session 01 / Why Containerization?

以環境一致性、交付與隔離模型，說明容器化的價值並辨識 VM 與 Container 的 Kernel 邊界

Session 02 / How Containers Work

知道 Container 是受隔離的 Process；以 Namespaces、cgroups、RootFS 解釋看似獨立的環境

Session 03 / Docker Images & Dockerfile

能讀懂 Dockerfile 的啟動合約、Layer 與 Cache，避免不必要的重複建置

Session 04 / Container Networking & Storage

透過可觀察的 Docker CLI 實驗，預測容器連線、隔離與資料持久化

Session 05 / From Docker to Kubernetes

由 dockerd／containerd／runc／CRI 推導 Kubernetes 編排需求與後續 CKA 章節

設計方式

依照 @lfd「Plan globally, teach adaptively」：先規劃完整學習路徑，再依實際理解逐堂撰寫。每堂保留來源、練習與回饋。互動圖用來呈現因果、邊界與差異，而不是增加裝飾。

學習內容使用 Docker、Linux Kernel 與 Kubernetes 官方技術文件查核；頁面不是公司環境的實際部署紀錄。
