Mission

使有軟體開發基礎、但非 SRE 的同事理解容器化的必要性、Kernel 隔離、Docker 封裝與運作，能銜接 Kubernetes / CKA 架構課程。每個 Session 30 分鐘，Lessons 是較短、可獨立複習的單位。

SESSION 01約 30 分鐘

Why Containerization?

能力目標：以環境一致性、交付與隔離模型，說明容器化的價值並辨識 VM 與 Container 的 Kernel 邊界

  1. L01 · 為何容器化？VM 與 Container 的底層差異 已撰寫 / 未驗收

    練習成果：能判斷 Image 封裝哪些依賴，並解釋 VM 與 Container 啟動 API 時各使用哪個 Kernel
    依據：Docker Overview／Container、Docker Desktop · 證據與來源索引

SESSION 02約 30 分鐘

How Containers Work

能力目標：知道 Container 是受隔離的 Process；以 Namespaces、cgroups、RootFS 解釋看似獨立的環境

  1. L02 · Container 是什麼：Process、Namespace、cgroups 規劃中

    練習成果：能解釋 PID 視角與資源限制並非兩個 Kernel
    依據：Linux namespaces／cgroup v2 · 證據與來源索引

  2. L03 · RootFS 為何像是一套 OS？Docker Engine 扮演什麼角色 規劃中

    練習成果：能分辨 User Space 檔案和 Kernel，以及 CLI 與 dockerd
    依據：Docker Engine／Image Layers · 證據與來源索引

SESSION 03約 30 分鐘

Docker Images & Dockerfile

能力目標：能讀懂 Dockerfile 的啟動合約、Layer 與 Cache，避免不必要的重複建置

  1. L04 · Dockerfile：RUN、COPY、ADD、CMD、ENTRYPOINT 規劃中

    練習成果：能判斷建置與執行階段差異及預設啟動命令
    依據：Dockerfile reference · 證據與來源索引

  2. L05 · Layer、Build Cache 與 Multi-stage Build 規劃中

    練習成果：能預測修改源碼或 Lockfile 時會重建哪些步驟
    依據：Docker Build Cache／Multi-stage · 證據與來源索引

SESSION 04約 30 分鐘

Container Networking & Storage

能力目標：透過可觀察的 Docker CLI 實驗，預測容器連線、隔離與資料持久化

  1. L06 · Network A／B 隔離與雙網卡 API 規劃中

    練習成果：能分辨雙網卡服務與跨網路自動路由
    依據：Docker Bridge Network · 證據與來源索引

  2. L07 · Container Lifecycle、Writable Layer 與 Volume 規劃中

    練習成果：能判斷停止、刪除與重建對程式和資料的影響
    依據：Docker Storage／Volumes · 證據與來源索引

SESSION 05約 30 分鐘

From Docker to Kubernetes

能力目標：由 dockerd／containerd／runc／CRI 推導 Kubernetes 編排需求與後續 CKA 章節

  1. L08 · Docker CLI → dockerd → containerd → runc → Linux Kernel 規劃中

    練習成果：能區分 Docker Engine、OCI Runtime、CRI 與 Kubernetes 的責任
    依據：Docker Overview／Kubernetes CRI · 證據與來源索引
