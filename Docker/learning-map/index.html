Mission：由程式部署問題推導 Docker、Linux Container 的底層原理，再銜接 Kubernetes／CKA。五個 Session 各約 30 分鐘；一個 Session 可拆為多個較短、聚焦的 Lesson。

學習順序按概念依賴設計：部署需要的執行條件 → Kernel 與 Process → 隔離 → Image 與建置 → 網路與資料 → Runtime 與 Kubernetes。

SESSION 01約 30 分鐘

Why Containerization?

能力目標：從部署差異出發理解 Image、Process、OS、VM 與 Container 的 Kernel 邊界

  1. L01 · 為什麼需要 Container？ 已撰寫／未驗收

    預期成果：能說明環境漂移、封裝與 VM/Container 的差異資料：Docker What is a container／Overview · 官方查核

SESSION 02約 30 分鐘

How Containers Work

能力目標：知道 Container 裡的程式如何獲得不同資源視角與限制

  1. L02 · 一個 Process 怎麼看起來像獨立電腦？ 規劃中

    預期成果：由 Process 視角引入 PID／Mount／Network Namespace資料：Linux namespaces · 官方查核

  2. L03 · Container 如何限制資源並取得檔案？ 規劃中

    預期成果：解釋 cgroups、RootFS 與 Docker Engine 基本角色資料：Linux cgroup v2／Docker Engine · 官方查核

SESSION 03約 30 分鐘

Docker Images & Dockerfile

能力目標：理解 Image 如何建構以及指令順序對建置的影響

  1. L04 · Dockerfile：從指令到執行 規劃中

    預期成果：掌握 FROM／RUN／COPY／ADD、CMD 與 ENTRYPOINT資料：Dockerfile reference · 官方查核

  2. L05 · Image Layers 與 Build Cache 規劃中

    預期成果：觀察檔案修改如何影響 Cache，認識 .dockerignore 與 Multi-stage資料：Docker Build docs · 官方查核

SESSION 04約 30 分鐘

Networking & Storage

能力目標：能用 Docker CLI 實際測試不同網路的連線及資料存續

  1. L06 · Container 如何互相連線？ 規劃中

    預期成果：先建立 IP／Port 概念，實作 Network A/B、雙網路容器資料：Docker Bridge · 官方查核

  2. L07 · 停止或刪除 Container，資料會怎樣？ 規劃中

    預期成果：觀察 Lifecycle、Writable Layer、Bind Mount、Volume資料：Docker Storage · 官方查核

SESSION 05約 30 分鐘

Docker Architecture to Kubernetes

能力目標：分辨管理命令、Container Runtime、Kernel 與 Kubernetes 的職責

  1. L08 · Docker 與 Kubernetes 如何建立 Container？ 規劃中

    預期成果：能解釋 CLI → dockerd → containerd → runc 與 kubelet → CRI資料：Docker Overview／Kubernetes CRI · 官方查核
